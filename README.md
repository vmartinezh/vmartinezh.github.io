# MH Digital Studio

Sitio de presentación de MH Digital Studio: desarrollo web, mantención de equipos, consultoría TI y seguridad básica para pymes.

Publicado en GitHub Pages: https://vmartinezh.github.io

## Editar

- **Datos de contacto** (WhatsApp, correo, Instagram): `js/config.js`. Todo el sitio toma los datos de ahí.
- **Textos y servicios**: `index.html`.
- **Colores y estilos**: variables al inicio de `css/styles.css`.
- **Proyectos del portafolio**: sección `#proyectos` en `index.html`; capturas en `assets/proyectos/` (1280×800).

Es HTML, CSS y JavaScript sin dependencias ni compilación: se edita, se hace commit y GitHub Pages lo publica en uno o dos minutos.
